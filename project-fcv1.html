Project / Engineering scope

FCV1

A custom modular flight controller for experimental platforms.

← All projects

One controller, multiple possibilities

FCV1 is a custom-designed modular flight controller intended for rockets, weather balloons, CanSats, and quadcopters.

Intended applications

  • Rockets
  • Weather balloons
  • CanSats
  • Quadcopters

Development & validation

Each application requires its own firmware, interfaces, and validation. Suitability must be checked against the platform and mission requirements.

These are intended applications, not claims of flight qualification. Hardware demonstrations and detailed validation records will be added when available.
